## 逐条复核

### 已修复（加固）

| 发现 | 位置 | 修复 |
|---|---|---|
| ERC20 `approve/transfer` 未用 SafeERC20（Aderyn L-10/L-11，Slither unused-return） | `Treasury.execute/convert`、`FeeLocker.claim` | 改为 `forceApprove` / `safeTransfer` |
| `nonReentrant` 不是第一个修饰符（Aderyn L-5） | `Treasury.convert` | 调整顺序 |
| `setPool` 无零地址检查、无事件（Aderyn L-7/L-8） | `LaunchToken.setPool` | 加 `ZeroAddress` 检查与 `PoolSet` 事件 |
| 构造函数地址参数无零检查（Slither missing-zero-check） | `LaunchFactory` 构造函数 | 加检查 |
| `positionManager.mint` 返回的 liquidity 未校验 | `LaunchFactory._mintLocked` | `liquidity == 0` 时 revert `NoLiquidity` |

### 判定为误报 / 有意设计（不改）

| 发现 | 位置 | 理由 |
|---|---|---|
| Aderyn H-1 外部调用后改状态（10 处） | `launch`、`distribute`、`execute`、`register`、`markGraduated` | 前三者有 `nonReentrant`；后两者的"外部调用"是 view（`ownerOf`/`balanceOf`）。工具不识别 OZ 修饰符 |
| Slither reentrancy-no-eth ×3 | `FeeLocker.distribute` | 有 `nonReentrant`；`_push` 用低级 call 是为了黑名单兜底 |
| Slither divide-before-multiply | `LaunchFactory._floorTick` | `tick / spacing * spacing` 就是向下对齐到 tick 间距，有意为之 |
| Slither incorrect-equality ×2 | `LaunchToken._update`（`block.number == launchBlock`）、`Treasury.execute`（`bal == 0`） | 有意的精确判断 |
| Slither unused-return ×7 | 解构 `slot0()` / `positions()` / `mint()` 的部分返回值；`_initialBuy` 忽略 `amountOut` | 解构时忽略不需要的字段；首购的滑点由 `minTokensOut` 参数保护 |
| Slither timestamp | `deadline: block.timestamp` | Uniswap 标准用法 |
| Aderyn L-9 string 可 immutable | `LaunchToken.logo/description` | Solidity 不支持 string immutable |
| Aderyn L-1 中心化风险 | `onlyOwner` 参数函数 | 设计如此；owner 主网前转多签 |
| Aderyn L-6 PUSH0 | 全部 | Arc 为 Osaka 基线，支持 PUSH0 |

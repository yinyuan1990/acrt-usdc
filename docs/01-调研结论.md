# 01 · 调研结论：对标 pons，在 Arc（USDC 公链）上做发射平台

> 更新：2026-09-02 · 状态：已定稿

## 1. 对标产品 pons（ponsfamily.com）

**定位**：Robinhood Chain（Chain ID 4663）上的代币发射 + 交易平台。

**真实机制（来自 pons 官方文档，非二手总结）**

| 项目 | pons 做法 |
|---|---|
| 发币 | 一笔交易：铸 10 亿固定供应 + 创建 Uniswap **V3** 池 + LP 仓位 NFT 存入 Locker **锁定** |
| 交易 | **没有 bonding curve，没有迁移**。从第一秒起一直在同一个池子交易 |
| 计价 | 只对 WETH |
| 毕业 | 池内配对 WETH ≥ 4.2 ETH → `graduated = true`，仅是状态标志，**什么都不发生** |
| 手续费 | 池费 1%；创建费 0.0005 ETH |
| 分成 | 创作者 70% / 协议 30%（发币时快照，永不变）；创作者手动 claim，未领的由 pons 自动化代领打款 |
| 协议收入 | 80% TWAP 回购销毁 PONS（官方承认"尚不是不可变"），20% 运营 |
| 防狙击 | 发射后前 2 个区块：首块仅创作者可买；窗口内每钱包最多持有 5%、单笔最多买 5.5%；卖出不限 |
| 其他 | 社区接管 (CTO) 改创作者收款地址；代币元数据全部上链 |

**合约面**：`Factory` + `Locker` + `LaunchToken`，底层 Uniswap V3。前端只需监听 `TokenLaunched` 与池 `Swap` 事件。

**关键结论**：pons 的"三重收入"（创建费 / 毕业前手续费 / 毕业后手续费）中，后两项是**同一个池子的同一条手续费流**，"毕业后仍有收入"是因为 LP 从未迁移、从未销毁。

## 2. Arc 链关键事实

| 项目 | 事实 |
|---|---|
| 主网 | **2026-09-16** 公开主网（官方博客 8/5 公告）；当前私有主网 + 公开测试网 |
| Gas | **USDC 原生 gas**。原生余额 18 位精度；ERC-20 接口在 `0x3600…0000`（6 位精度）；同一资产同一余额，无 WETH 式包装币 |
| EVM | 兼容（Osaka 基线）；Solidity / Foundry / Hardhat / viem / ethers 直接可用；viem 内置 `arcTestnet` |
| 性能 | 0.5s 出块，确定性即时最终性，1 确认即终局；费用目标 ~$0.01/笔 |
| DEX | Uniswap **V4** 将在 9.16 主网同步部署（地址未公布）；测试网**没有任何 Uniswap** |
| 生态 | Chainlink / RedStone（预言机）、Alchemy / QuickNode（RPC）、Blockscout（arcscan）、Curve、Aave |
| Circle 配套 | CCTP、Gateway / Unified Balance、App Kit（Bridge/Swap/Send）、Circle Wallets、faucet.circle.com |
| 治理 | 许可制验证者集合；Arc LLC 声明"你自行负责合规与牌照" |
| 测试网 | Chain ID `5042002`，RPC `https://rpc.testnet.arc.io`，浏览器 `testnet.arcscan.app` |

**与标准 EVM 的差异（直接影响我们）**

1. `PREVRANDAO` 恒为 0（我们不需要随机数，无影响）
2. **USDC 黑名单协议层强制执行**：涉及黑名单地址的任何原生转账 revert。合约中所有 USDC 转出必须考虑失败路径
3. 禁止 burn / 禁止转零地址；`SELFDESTRUCT` 会把合约 USDC 一并转走
4. 区块时间戳非严格递增，排序用区块号
5. 基础费不销毁，归出块者
6. 发射币 18 位 vs USDC 6 位，价格换算需 10^12 缩放（pons 两边都是 18 位，公式不能照抄）

## 3. 结论

1. **可行，且是首发窗口**。pons 模式在 Arc 上可 1:1 复刻且更简单：价格天然美元计价、不需要 ETH 预言机、用户只需一种资产（USDC 同时是 gas 和交易货币）。
2. **技术路线：直接进池（pons 式），不做 bonding curve**。三重收入一条不少，省掉迁移逻辑与迁移风险。
3. **自己部署一套 Uniswap V3**（许可证已到期可自由部署）。测试网今天就能跑，主网 day-1 不依赖 Uniswap 官方进度。官方 V4 上线后作为后续升级（新 Factory 走 V4，老代币留 V3）。
4. **LP 必须"锁定"而非"销毁"**。销毁后无人能 collect 手续费，长期收入与创作者永久分润归零。
5. **"自动到账"用 keeper 定期 collect + 分发实现**，保留兜底 claim。不能在 swap 内同步打款（V3 做不到；且 Arc 黑名单 revert 会卡死池子）。
6. **合规**：Circle 系许可链，对外措辞偏"社区代币发行基础设施"，做好风险披露；平台币不对外喊"分红/收益"。

## 已知坑

- **PowerShell 别用 `Get-Content | Set-Content` 或 `-replace` 改源码**，会把 UTF-8 当 GBK 破坏 `… · →` 等字符并加 BOM；改文件用编辑工具或 node 脚本。
- PowerShell 里 `$`、`@`、引号转义麻烦，远程命令写成 `.sh` 用 `ops/ssh.mjs --script`。
- Foundry：`vm.prank` 会被紧随的 view 调用消耗，先把参数读到局部变量再 prank；代币里的自定义错误经 Uniswap 池会被包成 `"TF"`。
- Arc 公共 RPC `rpc.testnet.arc.io` 偶发 `-32603 internal error`，交易可能已成功但拿不到回执，查链上状态确认即可。
- 服务器 `/root/.local` 有用户级 urllib3 v2，会让系统 certbot 崩溃；`certbot.service` 已加 `PYTHONNOUSERSITE=1` drop-in，手动运行也要带。

## "美股"对标 pons（9.5 调研，**Arc 上暂不可做**）

pons 的做法：**不自己发股票代币**，把 Robinhood 在 Robinhood Chain 发的股票代币当作发币的报价资产（`pairToken`）。发币表单 "Paired asset" 下拉列了 ETH + 55 个股票/ETF（NVDA、TSLA、AAPL、SPY、QQQ、GLD、CRCL、MSTR、SPCX、FIG…）+ cbBTC + USDG；选 TSLA 后整条曲线、V4 池、创作者手续费都以 TSLA 计价；首页 "Stocks" 按钮是"股票计价发射"的筛选弹窗。合约（`PonsV2LaunchFactory`）：owner `setPairTokenApproved` 白名单 + `setPairTokenEconomics(pairToken, phantomQuote, graduationThreshold, decimals)` 按该资产精度单独设开盘储备与阈值，精度 ≥ 6，无预言机（美元换算在前端）。

Arc 现状：**没有任何股票代币**。Arc 生态伙伴里有 Dinari（dShares）、Robinhood、Securitize，但 Dinari 文档的支持链是 Ethereum / Arbitrum / Avalanche / Base / HyperEVM / Plume，无 Arc（"想上你的链请邮件 hello@dinari.com"）；Robinhood 股票代币只在 Robinhood Chain / Arbitrum；Backed、Ondo 也不在 Arc。

若将来有：技术改动约两周——Factory/PriceMath 每个发射带 `quoteToken` + admin 白名单与按精度的经济参数；FeeLocker 卖成该报价资产（或经 X/USDC 池换 USDC）；Treasury `convert`；索引器/前端价格以报价资产计 + RedStone/Chainlink 股票行情折美元、发币页配对资产下拉、交易面板余额/授权切换。**风险**：① 合规——股票代币是证券、Reg S 禁美国人、合约有转账限制器（被拉黑地址卖出会回滚），Circle 系许可链上做需先拿法律意见；② 流动性——用户手里得先有 TSLA 代币。**建议**：先不动合约，等 Dinari/Robinhood 上 Arc 主网再启动；可先邮件 Dinari 问 Arc 时间表并谈首批合作。

## 税币模式（9.5 已完成，详见上方 v2.3）

对标 dyorswap.org（Arc 上，`/createTax`）：发币时选"基础币 / 税币"，税币有买入税、卖出税各 1–10% 滑块；"税费分配"是 4 个比例滑块合计 100%（**没有自填地址**）：创作者资金钱包（开发者、营销等，= 发币钱包）/ 销毁 / 分红（持有者奖励，默认 100%）/ 流动性；它是曲线 + 迁移路线，**税币只允许迁 Uniswap V2**——因为 V3 卖出会校验池子实收足额，常规 fee-on-transfer 会回滚。我们的建议：第一版做"创作者钱包（可填任意收款地址，比它灵活）+ 销毁"两个滑块；分红（要新合约 + 措辞红线）和自动加流动性（V3 锁定仓位要双边配比）放二期。

我们在 V3 上的兼容写法（不改 Uniswap）："税加在外面"：买入时池子原量转出、代币合约把 x% 转税库，用户实收 (1−x%)；卖出时用户足额转 N 进池、合约**额外**从其余额划 N×y% 到税库，最大可卖 = 余额 ÷ (1+y%)。FeeLocker / Treasury / PositionManager 免税。税率 immutable，发射后谁都改不了。

**老板已定（9.5）**：税分给**营销税 / 团队税**两个自填地址（默认都是发币钱包），比例创作者定，买卖两边共用同一套；上限买卖各 10%；协议不抽成；分红、销毁、自动加流动性都不做（二期候选）。

## 我们原来缺的（已补）

1. **实时活动流**：pump.fun 顶栏是"某钱包买入 $X 的 Y / 新币创建"，不是价格 ticker。已增加活动条（买/卖/新发射，带钱包头像），价格 ticker 保留在第二行
2. **排序器 + 视图切换**：Tabs 之外增加排序下拉（成交额 / 市值 / 创建时间 / 毕业进度），并加 **Pulse 三栏视图**（新发射 / 冲刺中 / 已毕业）
3. **Thread（评论）**：代币页新增 Thread 标签，评论 + 回复框，创作者评论带标识。社交层是 pump.fun 留存的核心
4. **代币页头部动作**：复制合约地址、分享、收藏、区块浏览器
5. **进度说明文案**：毕业卡片增加一段解释"池内 USDC 达阈值即毕业，LP 永久锁定，毕业后不迁移、手续费不变"
6. **交易面板两步下单**：设置齿轮（滑点）改 Popover；点击买/卖先弹 Review 确认框（Uniswap 模式），价格影响 >5% 橙、>10% 红
7. **全局搜索 Command 面板**（⌘K）：搜代币名/符号/地址
8. **Profile**：增加"我创建的 / 我持有的"分组

## 保留的差异化（对标里没有、我们要突出）

- 全部美元计价，无需换算
- 毕业不迁移，创作者分润"毕业前后不变"在卡片与代币页显性提示
- 创作者中心"自动到账"记录
- 销毁与国库看板作为一级页面

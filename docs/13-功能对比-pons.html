ArcLaunch vs pons · 功能对比

更新 2026-09-05 · 对照对象 ponsfamily.com（Robinhood Chain）· 依据：pons 官方文档 docs.ponsfamily.com、其 launchpad / create 页面、GitHub ponsdotdev/ponsfamily；ArcLaunch 以 arclaunch.top 当前线上版本（合约 v2.1）为准

先说清楚"两个路子"

pons 有两代机制：v1（直接进 Uniswap V3 池、LP 锁定、毕业只是标志）和 v2（全部供应铸进自研 bonding curve → 攒够阈值迁入 Uniswap V4 + 自研 Hook 收费，支持 ETH / USDG / cbBTC / 代币化股票多种报价资产）。pons 网站现在默认展示 v2。

ArcLaunch 走的是 v1 路子（直接进池、不做曲线、不迁移），原因见 docs/01 §3、封存的曲线路线见 docs/10。所以下面的对比分三块：① 与 pons v1 同路子的逐项对比；② pons v2 独有、我们有意不做的；③ ArcLaunch 独有的。

三、pons 有、ArcLaunch 有意不做

项目pons为什么我们不做
Bonding curve + V4 迁移v2 主栈：曲线合约 → 阈值后迁 Uniswap V4 + Hook 收费路线已封存（docs/10）：多 5–6 个自研合约、用户本金在毕业前放在自研合约里，审计从建议变必须；Arc 测试网无官方 V4 无法提前测。曲线的"公平发射"要素用统一开盘市值 + V3 单边仓位已实现
多种报价资产 / 代币化股票（"美股"）发币表单 "Paired asset" 下拉：ETH + 55 个 Robinhood 股票代币（NVDA / TSLA / AAPL / SPY / QQQ / CRCL / SPCX…）+ cbBTC + USDG；选中后整条曲线、V4 池、创作者手续费都以该股票代币计价；首页 "Stocks" 按钮筛选股票计价发射。合约层 owner 白名单 + 按资产精度单独设经济参数，无预言机不是不想做，是 Arc 上没有原料：Arc 链上目前没有任何股票代币（Dinari dShares 支持链无 Arc，Robinhood 股票代币只在 Robinhood Chain）。技术上把报价资产泛化约两周可做，但涉及证券合规（Reg S、转账限制器）需先拿法律意见。等 Dinari / Robinhood 上 Arc 再启动，详见 docs/12
前 5 秒 99% 递减狙击税v2 曲线阶段属于曲线路线；v1 路子用区块窗口 + 持仓 / 单笔上限，效果等价且不产生"税"这种争议收入
ETH 价格预言机用 DeFiLlama 把 WETH 价折美元不需要——池子本身就是美元计价

四、ArcLaunch 独有（对外可强调）

机制层

  • 统一开盘市值（公平发射），创作者不能自选价格
  • 创作者只收 USDC，代币侧手续费自动换汇，Keeper 自动到账
  • 社区接管 48 小时时间锁 + 创作者一键否决（合约强制）
  • 协议收入 80% 多签 / 20% 回购销毁，每 7 天结算，比例、周期、收款地址全部 immutable（pons 自己承认"尚不是不可变"）
  • 创建费可开关 / 可白名单减免 / 可设 0
  • 税币模式：买卖税 0–10% 创作者设定，分营销 / 团队两个自填地址，发射后 immutable、V3 池直接交易、协议不抽成
  • 管理员权限全表公开，合约不可升级

产品层

  • 回购销毁看板一级页面，每次结算 / 回购 tx 可查；平台不设资金池
  • 排行榜、山丘之王、Pulse 三栏视图、实时活动流
  • Thread 钱包签名评论、收藏 Watchlist
  • 站内 CTO 申请 + 后台审核直接发链上提案
  • 管理后台（数据 / 代币 / CTO / 参数 / Keeper）
  • 中英双语、两套主题

## 3. 过程中发现并修复的问题

| # | 问题 | 处理 |
|---|---|---|
| 1 | `forge script` 无法在 Arc 上做任何 USDC 转账：USDC 合约调用黑名单预编译 `0x1800…0001`，本地 EVM 没有 → revert | 部署脚本不碰 USDC 可用；涉及 USDC 的操作改用 `cast send` 直发（`ops/smoke-cast.sh`） |
| 2 | Uniswap V3 仓位 `tokensOwed` 只在 collect 时刷新，链上读不到"待收手续费" | Keeper 改用索引器统计的成交量 × 1% 估算，达阈值或超时即 distribute |
| 3 | 索引器回填按事件类型分批，导致 `volume_since_distribute` 被更早的 FeesDistributed 清零 | 改为全局按 (区块, logIndex) 顺序重放 |
| 4 | Keeper 传地址字符串当 account → viem 走 `eth_sendTransaction` 被节点拒绝 | 用钱包客户端自带私钥账户本地签名 |
| 5 | 发币后跳转代币页，索引器滞后 2–3 秒返回 404，页面停在"未找到" | `useToken` 对 404 重试 15 次 × 2 秒 |
| 6 | Windows npm 11 生成的 lockfile 缺 Linux 可选依赖，服务器 `npm ci` 拒绝 | 镜像内改用 `npm install` |
| 7 | Circle 水龙头 reCAPTCHA v3 拦截无头浏览器 | puppeteer-extra-stealth + 可见窗口 + 拟人操作可通过（`ops/faucet.mjs`） |
| 8 | 服务器 git smart-HTTP 被拦，`forge install` 失败 | 依赖改用 GitHub tarball |
| 9 | `LaunchFactory.launch` / `LaunchToken` 构造函数 Stack too deep | 拆内部函数 + 构造参数改 struct |
| 10 | 服务器 sshd 关闭了公钥登录；每小时 100+ 次 root 暴力破解 | 开公钥、fail2ban、ufw（见 05） |

## 4. 已知限制 / 待办

- **Thread 讨论区**未实现（需要链下签名评论服务），页面显示"即将上线"
- **平台币 $ArcLaunch 与 TWAP 回购**：Treasury 合约已就位（82/18 immutable），平台币未发，`execute()` 未配置
- **钱包**：目前仅注入式钱包（MetaMask / Rabby / Coinbase 扩展）；WalletConnect 需申请 projectId
- **Logo 上传**：暂为 URL 或 emoji，未接图片存储
- **管理权**：owner 仍是部署钱包，主网前须转 Safe 多签
- **审计**：未做第三方审计
- 前端实时性走轮询（4–8s），WS 推送已在后端就位，可后续接入
- 测试网 Keeper 阈值 0.01 USDC / 10 分钟；主网参数 50 USDC / 30 分钟

## 5. 人工验收指引

1. 钱包添加 Arc Testnet（RPC `https://rpc.testnet.arc.io`，chainId `5042002`，符号 USDC）
2. 到 https://faucet.circle.com 领 20 USDC（选 Arc Testnet）
3. 打开 https://launch.hzmrbq.com → 连接钱包 → 发币（2 USDC 创建费 + 可选首购）
4. 在代币页买卖；观察 K 线、成交、持有人、毕业进度
5. 10 分钟内到 `/creator` 查看自动到账记录（每笔带 ArcScan 链接）
6. `/burn` 查看国库余额随创建费与协议分成增长

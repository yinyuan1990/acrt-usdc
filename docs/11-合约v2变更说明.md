## 1. 改了什么

| # | 变更 | 为什么 | 涉及 |
|---|---|---|---|
| 1 | **统一开盘市值**。`LaunchParams` 去掉 `sqrtPriceX96`，Factory 内按 `startMcapUsdc`（初值 5,000 USDC）用 `PriceMath` 算起始价。admin 可在 500 – 10,000,000 USDC 之间调，仅影响新币 | 公平发射的核心要素："所有币同一开盘价，创作者定不了" | `LaunchFactory.sol`、`web/create`、`indexer /api/config /api/launch-quote`、ops 脚本 |
| 2 | **创作者只收 USDC**。`FeeLocker.distribute(token, minUsdcOut)`：collect 后把代币侧手续费在同一池内卖成 USDC，合计按 75/25 分。换汇失败（滑点保护）→ 代币暂存 `unconvertedTokenFees` 下次重试，USDC 部分照发 | 计划书第 6 条；对齐 pons v2 的"只收报价币" | `FeeLocker.sol`、keeper、索引器 `fee_events` 表 |
| 3 | **社区接管时间锁**。admin 不能再即时 `setPayout`；改为 `proposePayout` → 48h → 任何人 `executePayout`；期间创作者可 `cancelPayoutProposal`，创作者自己换地址也会清掉提案 | 关掉"管理员偷创作者分成"这个唯一敏感权限 | `FeeLocker.sol` |

**未改**：`LaunchToken`、`Treasury`、Uniswap V3 四个合约、分成 75/25、回购 82/18、供应量、限购规则。

## 2. ABI 变化一览（对接方必读）

```
LaunchFactory
  - struct LaunchParams 去掉 uint160 sqrtPriceX96      → launch((string,string,string,string,(string,string,string),uint256,uint256))
  - setLaunchParams(uint256,uint256,uint16,uint16,int24,int24) → setLaunchParams(uint256,uint256,uint16,uint16,uint256 startMcapUsdc)
  + startMcapUsdc() view
  - error StartPriceOutOfRange(int24)                    → StartMcapOutOfRange(uint256)

FeeLocker
  - constructor(nfpm, treasury, owner)                   → constructor(nfpm, router, treasury, owner)
  - distribute(address)                                  → distribute(address token, uint256 minUsdcOut) returns (usdcCollected, usdcFromToken)
  - event FeesDistributed(token, quoteToCreator, quoteToProtocol, tokenToCreator, tokenToProtocol, creatorPaid)
    → FeesDistributed(token, quoteToCreator, quoteToProtocol, tokenConverted, usdcFromToken, creatorPaid)   （类型不变，topic 不变，语义变）
  + event TokenFeesDeferred(token, amount)
  + unconvertedTokenFees(token) view
  - setPayout(token, newPayout)  仅当前收款地址可调（owner 不再能调）
  + proposePayout(token, newPayout) onlyOwner
  + executePayout(token)            任何人，需 eta 到期
  + cancelPayoutProposal(token)     当前收款地址或 owner
  + pendingPayout(token) view returns (newPayout, eta)
  + CTO_DELAY = 48 hours, POOL_FEE = 10000
  + events PayoutProposed / PayoutProposalCancelled
```

索引器 `fee_events` 表：`token_creator / token_protocol` 两列删除，新增 `token_converted / usdc_from_token`（`migrate()` 自动执行）。`/api/creator/:a` 的 `payouts[].tokens` 改为 `payouts[].usdcFromToken`。

## 3. 测试覆盖（18 / 18）

新增或改写：
- `launch_everyTokenOpensAtSameMcap`：连发 6 个币，市值全部 ≈ 5,000
- `launch_adminChangesOpeningMcapForNewLaunchesOnly`：改参数只影响新币；越界 revert
- `fees_distributeSplits75_25_usdcOnly`：创作者与国库只收 USDC，Locker 不留代币；二次分发只剩换汇自身产生的 1% 尾巴
- `fees_swapFailureDefersTokensButPaysUsdc`：minOut 过高 → 代币暂存、USDC 照发；下次成功清空
- `payout_creatorRotatesInstantly_strangerCannot`：owner 也不能走即时路径
- `payout_ownerTakeoverNeedsDelay`：48h 前 revert，之后任何人可执行
- `payout_creatorCanVetoTakeover`：显式否决 / 换地址隐式否决 / 陌生人不能否决

## 3b. 抢买 / 夹击模拟（`test/Sniping.t.sol`，9 / 9）

用 10 个机器人钱包模拟，结论按"挡住了什么 / 挡不住什么"分开写，对外解释时照抄即可。

| 场景 | 结果 | 说明 |
|---|---|---|
| 发射区块 10 个机器人同时买 | **全部被拒** | 发射区块只有创作者能从池子拿到币，与钱包数量无关 |
| 创作者借首购权抢自己的币 | **被拒** | 首购同样受 5.5% 单笔上限，$5,000 砸进 $5,000 池会 revert |
| 窗口内单钱包一口吃 3,000 USDC | **被拒** | 超 5.5% 单笔上限 |
| 窗口内单钱包切成 20 笔小单 | **停在 5%** | 持仓上限累计生效，切单无用 |
| 窗口内 10 个钱包各买 100 USDC | **每个 ≤ 5%，合计约 17%** | 每个地址都被压在 5% 以下 |
| 上述 10 个钱包窗口后把币转到一个地址 | **能合并，超过 5%** | **已知边界**：限购只管"从池子买"，转账不限。窗口降低集中度，不能让巨鲸不存在。对外只写"降低单地址持仓集中度"，不写"彻底防巨鲸" |
| 窗口结束后真人买 3,000 USDC | 正常成交 | 20 个区块（≈10 秒）后全部限制解除 |
| 机器人窗口内买了就卖 | 能卖，亏两次 1% | 卖出永不限制，也没有隐藏出口 |
| 机器人在 Keeper 分费前砸盘（夹击换汇） | **换汇被 97% 滑点保护拒绝**，USDC 照发，代币暂存下次再换；机器人买回后**持币变少** | Keeper 先 dry-run 报价再传 minOut |
| 机器人自己调 `distribute(token, 0)` 夹击 | **亏钱** | 换汇量只有机器人自身搬动量的 <5%，两次 1% 池费吃掉全部收益 |
| 机器人抢跑普通用户的买单 | 用户 99% 滑点保护 revert，不会多付 | 任何 AMM 都有的场景，前端按最新报价设 `amountOutMinimum` |

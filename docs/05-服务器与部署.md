## 部署布局（与现有业务隔离）

```
/opt/arclaunch/
  docker-compose.yml
  .env                      # 只放非密钥配置；keeper 私钥用 docker secret / 环境注入
  web/                      # Next.js 前端（standalone 构建）
  indexer/                  # 链上事件索引 → Postgres → REST/WS
  keeper/                   # 调 distribute()/execute() 的机器人，钱包只放 gas 用 USDC
  nginx/arclaunch.conf      # 挂到 /etc/nginx/conf.d/，独立 server_name
```

| 容器 | 端口（仅 127.0.0.1） | 说明 |
|---|---|---|
| `arclaunch-web` | 3100 | Next.js |
| `arclaunch-indexer` | 3101 (API) / 3102 (WS) | 监听 Arc RPC/WSS，写 Postgres |
| `arclaunch-db` | 5432（不暴露） | Postgres 16，volume 持久化 |
| `arclaunch-keeper` | — | 定时任务，无入站端口 |

nginx 新增 server block（需要一个域名，例如 `arclaunch.xyz` / `app.xxx.com`），Certbot 自动签证书；不改动 `habo.conf`。

## 安全模型：什么在链上、什么在后台

| 层 | 内容 | 被攻破的后果 |
|---|---|---|
| 链上（不可篡改） | Factory / Token / FeeLocker / Treasury / Uniswap V3。资金、分成、LP 锁定、毕业规则 | 唯一能丢钱的地方 → 审计、参数 immutable、不可升级 |
| 链下·只读 | 索引器、前端 | 页面错/打不开，资金不受影响，用户可直接调合约 |
| 链下·辅助 | Keeper、图片存储、评论 | Keeper 钱包只有少量 gas；`distribute()` / `execute()` 任何人可调，创作者可手动 claim |
| 管理后台 | 创建费开关、白名单、CTO 收款地址、前端精选/隐藏 | 链上参数改动需 **多签（Safe）**；前端标记只影响展示 |

结论：**后台全挂，用户一分钱不会少；能动钱的只有合约。**

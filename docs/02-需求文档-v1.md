## 1. 产品定位

ArcLaunch：为 Circle Arc 公链（9.16 主网、USDC 原生 gas）打造的代币发射与交易平台。采用 pons 已验证的"直接进池"模式，修复其体验缺陷，全程美元计价。

一句话：**发币零成本，统一开盘价，交易全美元，创作者永久自动分润（只收 USDC），平台收入链上可查。**

对外措辞边界：不写"Arc 官方"、"首个"、"必然超越 pons"、"100% 无 BUG"；用"为 Arc 生态打造 / Arc 原生发射平台"、"主网上线同期"。

## 2. 核心机制（修正版）

### 2.1 发币（Launch）

一笔交易完成：
1. 部署 `LaunchToken`（固定供应 10 亿，18 位）
2. 创建 Uniswap V3 池：`Token / USDC`，费率 1%（10000）
3. 以**平台统一开盘市值**（合约参数 `startMcapUsdc`，初值 5,000 USDC）算出起始价，**单边注入全部代币**（右格 USDC 为 0）。创作者没有价格输入项
4. LP 仓位 NFT 转入 `FeeLocker`，**无解锁函数**
5. 可选：创作者首笔买入（同一交易内，抢在机器人前）
6. 收取创建费（若开启，当前 $1）→ 直接转入生态多签（`Factory.feeRecipient`）
7. 元数据（名称/符号/logo/描述/社交链接）写入代币合约

### 2.2 交易

- 全部买卖在同一个 V3 池内，从发币第一秒到永远
- 池费 1% 累积在 LP 仓位内

### 2.3 毕业（Graduate）

- 条件：池内配对 USDC 本金 ≥ 阈值（初稿 5,000–10,000 USDC，admin 可调，仅影响新币）
- 效果：`graduated = true`，前端挂标识、进入"已毕业"榜单、触发平台币激励（见 §5）
- **不迁移、不改费率、不改分成**

### 2.4 手续费分配

- `FeeLocker` 持有所有 LP NFT
- keeper 触发条件：单币累计未分手续费 ≥ X USDC **或** 距上次分发 ≥ N 分钟
- 分发：`collect()` → 代币侧手续费在同一池内卖成 USDC → 合计 USDC 按 75% 创作者 / 25% 协议结算合约推送。**创作者和协议侧只收 USDC，不收发射币**
- 卖出失败（滑点保护未满足等）→ 代币留在 Locker 记为 `unconvertedTokenFees`，下次分发重试；**USDC 部分照常发放**，不受影响
- 创作者收款失败（USDC 黑名单等）→ 记入待领余额，创作者可 claim；不影响其他人交易
- 任何人可调用 `distribute(token, minUsdcOut)`（permissionless），keeper 只是保证及时性；keeper 先 dry-run 得到换汇结果再以 97% 作为 `minUsdcOut` 发交易
- 注意：换汇那笔卖单自身会在池内产生 1% 手续费，形成一条几何递减的尾巴，下次分发一并处理

### 2.5 发射保护（防狙击）

Arc 0.5s 出块，pons 的"2 个区块"须重算：
- 发射区块：仅创作者首笔买入可执行
- 保护窗口（初稿 20 个区块 ≈ 10 秒，admin 可调仅影响新币）：每钱包持有 ≤ 5%、单笔买入 ≤ 5.5%
- 卖出与转账不限制；窗口结束后全部解除

### 2.6 社区接管（CTO）

- 创作者（当前收款地址）可随时**即时**更换自己的收款地址
- admin **不能即时**修改：走 `proposePayout` → 等待 **48 小时** → 任何人可 `executePayout`
- 等待期内原创作者可 `cancelPayoutProposal` 否决；创作者自己换地址也会自动清掉 admin 的提案
- 事件全部上链（`PayoutProposed / PayoutProposalCancelled / PayoutChanged`），前端在代币页与创作者中心提示
- 池子、LP、分成比例不受影响

## 3. 收入体系

| 收入 | 触发 | 标准 | 流向 |
|---|---|---|---|
| ① 创建费 | 发射时一次性 | 当前 **$1**，可调、可为 0；支持白名单减免 | 100% **直接进生态多签** |
| ② 交易手续费 | 每笔买卖 | 池费 1% | 0.75% 创作者 / 0.25% 协议（发射时快照） |

> 原文档的"收入②曲线阶段 / 收入③毕业后"合并为一条，因为是同一池子的同一条费流。毕业前后收入连续、无断点。

**协议 0.25% 的分配**（9.6 定稿，写死在合约）：
- 进入自动结算合约（代码名 `Treasury`，对外不叫"国库"），**每 7 天结算一次**，`execute()` permissionless，Keeper 到点触发
- **储备金 19%（0.19% of volume）→ 储备金多签**：创作者激励、运营、审计
- **开发团队 1%（0.01% of volume）→ 开发团队地址**：单地址 `0x14EDF5b1D23FA8A66a533fdd7EBFDe5C87d706d3`，测试网与主网同一个，部署时写死
- **ARCL 回购销毁 5%（0.05% of volume）→ 买 $ARCL 转入 `0x…dEaD`**（Arc 禁止转零地址）；平台币未配置前累积为回购金
- 结算后合约余额归零；**平台不设资金池**，所有收入终点只有多签与销毁地址
- 已作废：原 82/18、"阈值触发 + 单次限额 TWAP"、"排行扶持回购"

## 4. 参数表

| 参数 | 初值 | 可改？ | 生效范围 |
|---|---|---|---|
| 创建费 | 1 USDC | **否**（constant，无开关、无白名单） | 全部 |
| 创建费收款地址 / 储备金 19% 收款地址 | 储备金多签（同一个） | **否**（immutable，部署时写死） | 全部 |
| 开发团队收款地址（1%） | `0x14ED…06d3` 单地址 | **否**（immutable，部署时写死） | 全部 |
| 协议 25% 分成收款合约 | Treasury | **否**（immutable） | 全部 |
| 平台币地址 | 空 | 只能设一次 | 全部 |
| 开盘市值 | 5,000 USDC | admin 可改（硬边界 500 – 10,000,000 USDC） | 新发币 |
| 社区接管时间锁 | 48 小时 | **否**（constant） | 全部 |
| 池费率 | 1% | 否 | 全部 |
| 创作者分成 | 75% | **否**（发币时快照） | 该币永久 |
| 协议分成 | 25% | **否** | 该币永久 |
| 毕业阈值 | 10,000 USDC | admin 可改（硬下限 1,000 USDC） | 新发币 |
| 保护窗口 | 20 区块 | admin 可改（硬上限 7,200 块 ≈ 1 小时） | 新发币 |
| 窗口内持仓上限 / 单笔上限 | 5% / 5.5% | admin 可改（硬下限各 1%，不可能设成买不了） | 新发币 |
| 分发触发（Keeper，链下配置） | ≥ 50 USDC 或 ≥ 2 小时（9.6 由 30 分钟改） | 服务器 `.env` 可改 | 全部 |
| 1% 池费分配 | 创作者 75% / 储备金 19% / ARCL 回购销毁 5% / 开发团队 1% | **否**（constant） | 全部 |
| 结算周期 | 7 天 | **否**（constant） | 全部 |
| 税币上限 | 买、卖各 10% | **否**（constant） | 全部 |
| 供应量 | 1,000,000,000 | 否 | 全部 |

**权限模型**：合约不可升级；经济参数（75/19/5/1 分配、7 天周期、供应、时间锁时长、税率一旦发射）immutable；**所有资金去向地址（储备金多签 = 创建费收款 = 储备金 19% 收款、开发团队地址、协议分成收款合约）在部署时写死，任何人包括 admin 都改不了**；平台币地址只能设一次；创建费 1 USDC 与税率上限 10% 也是 constant（9.7 老板定，白名单删除）；仅剩开盘市值、毕业阈值、保护窗口、限购比例 4 个发射参数 admin 可调，每个都有硬边界，且仅影响新发币；新版本以新 Factory 部署，老币不动。

**admin 权限全表**（对外可公开）：

| 函数 | 作用 | 动谁的钱 |
|---|---|---|
| `Factory.setLaunchParams` | 毕业阈值（≥ $1000）/ 保护窗口（≤ 7200 块）/ 限购比例（≥ 1%）/ 开盘市值（$500–$1000 万） | 只影响之后新发的币，边界保证新币永远可交易 |
| `Locker.setFactory` | 部署时一次性接线 | 无 |
| `Locker.proposePayout / cancelPayoutProposal` | 社区接管提案（48h 后任何人可执行） | 创作者 75%，但有 48h 且创作者可否决 |
| `Treasury.configure` | 平台币地址，**只能调一次** | 无（决定 20% 买哪个币烧） |
| `Treasury.convert` | 结算合约持有的代币换成 USDC（留在合约内） | 只动协议自己那份，钱不出合约 |

admin **做不到**：动池子里的钱、动 LP、改 75/19/5/1 分配或 7 天周期、**改任何收款地址（多签 / 开发团队 / 创建费收款 / 协议分成收款）**、换平台币、改创建费、改税率上限、给谁免创建费、改已发币的税率、增发、冻结、暂停交易、升级合约、即时改创作者收款地址。

## 5. 平台币 $ARCL

**基础（9.6 定稿）**
- 协议 0.25% 每 7 天结算：储备金 0.19% 进多签，开发团队 0.01% 进团队地址，回购 0.05% 划入回购金，随后**分批**买 $ARCL 转入 `0x…dEaD` 销毁（每笔回购限价涨幅 1.5%、间隔 10 分钟、成交价不低于 10 分钟 TWAP 的 90%——合约层严防 MEV 夹击，9.7 定）
- 回购销毁看板 `/burn`，每笔带交易哈希
- 通过 ArcLaunch 自己的发射台发出，与用户同规则（$10,000 开盘市值）
- **团队零预留**：全部 10 亿进池、LP 永久锁定，团队仅持有首购部分；"团队份额锁仓"的旧表述作废

**增强（建议，待拍板）**
- 创建费可用 $ArcLaunch 支付并打折，支付部分直接销毁
- 质押 $ArcLaunch 的创作者分成上浮（如 75% → 80%），资金来自协议 25% 侧
- 每个毕业代币：创作者获 $ArcLaunch 奖励；毕业时持有者按快照空投小额 $ArcLaunch（生态基金出）
- 质押解锁首页"精选发射"位
- （高风险，需法务）质押领取 USDC 奖励

**上线节奏**：$ARCL 由项目方在正式站发射；未配置平台币期间 20% 部分作为回购金累积，配置后开始分批买入销毁。Keeper 每分钟检查，到冷却就调 `buyback()`；链上 TWAP 地板是主保护，Keeper 的 QuoterV2 3% 滑点只是第二道。

## 7. 系统组件清单

> 不是"只需 4 套合约"。链上 4 个自研合约 + 自部署 Uniswap V3（4 个）+ 链下 4 个服务。

**链上（不可篡改，唯一能丢钱的地方）**

| 合约 | 职责 |
|---|---|
| `LaunchFactory` | 发币、按统一开盘市值建池、注入、转 LP 到 Locker、收创建费、记录 launch 参数、`graduationStatus()` / `markGraduated()`、运营参数管理 |
| `LaunchToken` | ERC20 固定供应；链上元数据；发射窗口限制（只限从池子买出） |
| `FeeLocker` | 持有 LP NFT（无解锁）；`distribute(token, minUsdcOut)` permissionless：collect → 代币侧换 USDC → 75/25；换汇失败暂存重试；待领余额兜底；创作者即时换收款地址；admin 社区接管 48h 时间锁 + 创作者否决 |
| `Treasury`（对外称"自动结算合约"） | 接收协议 25% 分成（创建费不经它）；`execute()` 每 7 天一次：0.19% 转储备金多签、0.01% 转开发团队、0.05% 入回购金并买第一批；`buyback()` 每 10 分钟一批把回购金买成 $ARCL 销毁（1.5% 冲击上限 + TWAP 地板）；75/19/5/1、7 天、多签与开发团队地址 immutable；`convert()` 把持有的代币换 USDC |
| Uniswap V3 | 自部署 Factory / NonfungiblePositionManager / SwapRouter / QuoterV2（官方字节码） |
| `PriceMath`（库） | 市值 ↔ sqrtPriceX96 换算，链上链下同一份公式 |

**链下（挂了也不丢钱）**

| 组件 | 职责 |
|---|---|
| Keeper | 定时 dry-run + `distribute`（带 97% 滑点保护）、`markGraduated`、`Treasury.execute`（QuoterV2 报价 3% 保护）。钱包只付 gas，无合约权限 |
| 索引器 / API | 事件 → Postgres（tokens / trades / candles / holders / fee_events / burns），REST + WebSocket |
| 评论服务 | EIP-191 签名评论与点赞，限频 |
| 上传服务 | Logo 上传（魔数校验、≤1 MB、sha256 命名） |
| 前端 | Next.js，网页 + 手机自适应，两套风格，多钱包 |

## 9. 风险与合规

- Arc 许可制验证者 + Circle 品牌：对外措辞"社区代币发行基础设施"，不用"稳赚/分红/收益"

## 1. 产品定位

ArcLaunch：Circle Arc 公链（9.16 主网、USDC 原生 gas）上的代币发射与交易平台。复刻 pons 已验证的收入飞轮，修复其体验缺陷，全程美元计价。

一句话：**发币零成本，交易全美元，创作者永久自动分润，平台收入链上可查。**

---

## 2. 核心机制（修正版）

### 2.1 发币（Launch）

一笔交易完成：
1. 部署 `LaunchToken`（固定供应 10 亿，18 位）
2. 创建 Uniswap V3 池：`Token / USDC`，费率 1%（10000）
3. 以创作者设定的起始价，**单边注入全部代币**（右格 USDC 为 0）
4. LP 仓位 NFT 转入 `FeeLocker`，**无解锁函数**
5. 可选：创作者首笔买入（同一交易内，抢在机器人前）
6. 收取创建费（若开启）→ 协议国库
7. 元数据（名称/符号/logo/描述/社交链接）写入代币合约

### 2.2 交易

- 全部买卖在同一个 V3 池内，从发币第一秒到永远
- 池费 1% 累积在 LP 仓位内

### 2.3 毕业（Graduate）

- 条件：池内配对 USDC 本金 ≥ 阈值（初稿 5,000–10,000 USDC，admin 可调，仅影响新币）
- 效果：`graduated = true`，前端挂标识、进入"已毕业"榜单、触发平台币激励（见 §5）
- **不迁移、不改费率、不改分成**

### 2.4 手续费分配

- `FeeLocker` 持有所有 LP NFT
- keeper 触发条件：单币累计未分手续费 ≥ X USDC **或** 距上次分发 ≥ N 分钟
- 分发：`collect()` → 75% 转创作者收款地址、25% 转协议国库
- 创作者收款失败（USDC 黑名单等）→ 记入待领余额，创作者可 claim；不影响其他人交易
- 任何人可调用 `distribute(token)`（permissionless），keeper 只是保证及时性
- 手续费中的代币部分：同样按比例分发（或协议侧换成 USDC，待定）

### 2.5 发射保护（防狙击）

Arc 0.5s 出块，pons 的"2 个区块"须重算：
- 发射区块：仅创作者首笔买入可执行
- 保护窗口（初稿 20 个区块 ≈ 10 秒，admin 可调仅影响新币）：每钱包持有 ≤ 5%、单笔买入 ≤ 5.5%
- 卖出与转账不限制；窗口结束后全部解除

### 2.6 社区接管（CTO）

- admin 可修改某代币的创作者收款地址（仅此一项），用于原创作者跑路后的社区接管
- 池子、LP、分成比例不受影响

## 3. 收入体系

| 收入 | 触发 | 标准 | 流向 |
|---|---|---|---|
| ① 创建费 | 发币时一次性 | **可调，可为 0**；支持白名单减免 | 100% 协议国库 |
| ② 交易手续费 | 每笔买卖 | 池费 1% | 75% 创作者 / 25% 协议国库（发币时快照） |

> 原文档的"收入②曲线阶段 / 收入③毕业后"合并为一条，因为是同一池子的同一条费流。毕业前后收入连续、无断点。

**协议国库二次分配**（平台币上线后启用）：
- 82%：TWAP 回购 $ArcLaunch → 转入 `0x…dEaD`（Arc 禁止转零地址）
- 18%：生态基金（创作者激励、毕业奖励、运营、审计）
- 触发：国库余额 ≥ 阈值，`execute()` permissionless，keeper 调用
- 比例写入合约不可改

## 4. 参数表

| 参数 | 初值 | 可改？ | 生效范围 |
|---|---|---|---|
| 创建费 | 2 USDC | admin 可改、可关 | 新发币 |
| 创建费减免白名单 | 空 | admin 可改 | 新发币 |
| 池费率 | 1% | 否 | 全部 |
| 创作者分成 | 75% | **否**（发币时快照） | 该币永久 |
| 协议分成 | 25% | **否** | 该币永久 |
| 毕业阈值 | 10,000 USDC | admin 可改 | 新发币 |
| 保护窗口 | 20 区块 | admin 可改 | 新发币 |
| 窗口内持仓上限 / 单笔上限 | 5% / 5.5% | admin 可改 | 新发币 |
| 分发触发 | ≥ 50 USDC 或 ≥ 30 分钟 | admin 可改 | 全部 |
| 回购比例 | 82% / 18% | **否** | 全部 |
| 供应量 | 1,000,000,000 | 否 | 全部 |

**权限模型**：合约不可升级；经济参数（分成、回购比例、供应）immutable；运营参数（创建费、阈值、窗口）admin 可调且仅影响新发币；新版本以新 Factory 部署，老币不动。

## 5. 平台币 $ArcLaunch（沿用原文档，补充增强项）

**基础（原文档）**
- 国库收入 82% TWAP 回购销毁，18% 生态运营
- 首页链上销毁看板，每笔带交易哈希
- 通过 ArcLaunch 自己的发射台发出，与用户同规则
- 团队份额锁仓，链上可查

**增强（建议，待拍板）**
- 创建费可用 $ArcLaunch 支付并打折，支付部分直接销毁
- 质押 $ArcLaunch 的创作者分成上浮（如 75% → 80%），资金来自协议 25% 侧
- 每个毕业代币：创作者获 $ArcLaunch 奖励；毕业时持有者按快照空投小额 $ArcLaunch（生态基金出）
- 质押解锁首页"精选发射"位
- （高风险，需法务）质押领取 USDC 奖励

**上线时点建议**：先跑发射台 2–4 周，国库有余额、池子有深度后再启动 TWAP，避免回购被夹。

## 6. 前端需求

**通用**：网页 + 手机端自适应；两套风格可切换（见 `03-UI风格方案.md`）；全部美元计价；钱包连接（MetaMask / Rabby / WalletConnect / Coinbase）；后续接 Circle App Kit（Bridge / Unified Balance）作为充值入口。

| 页面 | 内容 |
|---|---|
| Explore（首页） | 进行中 / 已毕业 / 新发射 / 热门 榜单；实时 ticker；搜索；平台今日数据（发币数、成交额、手续费、销毁） |
| 代币详情 | K 线（TradingView lightweight-charts）、买/卖面板、毕业进度条、持有人分布、交易流水、创作者信息与分成、社交链接 |
| 发币 | 名称/符号/logo/描述/社交；起始价或起始市值；首笔买入金额；创建费显示（含减免/免费状态）；一键发射 |
| 创作者中心 | 我发的币、累计分润、每笔自动到账记录（tx hash）、待领余额与 claim、修改收款地址 |
| 销毁 / 国库看板 | 国库余额、累计收入拆分（创建费 / 手续费）、每次回购销毁记录、$ArcLaunch 流通与已销毁 |
| 个人页 | 持仓、交易历史 |
| 排行榜 | 24h 成交额、涨幅、持有人数、创作者收入榜 |

**移动端要点**：底部 Tab 导航；交易面板改为底部抽屉；表格转卡片；K 线可横滑；发币表单分步。

## 9. 风险与合规

- Arc 许可制验证者 + Circle 品牌：对外措辞"社区代币发行基础设施"，不用"稳赚/分红/收益"
- 风险披露常驻：代币为用户创建、可能归零；名称可被仿冒、以地址为准
- 建议做地区限制（前端层）
- 平台币激励措辞用"质押奖励 / 社区激励"
